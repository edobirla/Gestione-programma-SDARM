## 🎯 Goal

Desktop app (Mac + Windows) to run a full Seventh-day Adventist weekly service from one control panel.
The operator sits at the back of the hall, prepares the program the same morning, and during the
service projects hymns, Bible verses, presentations (PDF/PPTX), videos, a break countdown timer,
background music, a bell, and an offering QR — all onto a **second screen** (iPad via Sidecar now;
in church will be a normal TV monitor).

"Done" = the operator never has to touch the projected screen; everything (incl. slide advance,
video transport, audio) is controlled from the app, and projection looks professional.

Packaging (PyInstaller .app + Windows .exe) comes **last**, after all features are stable.

## ❌ Failed Attempts / Hard-won Knowledge

### PowerPoint AppleScript PNG export
- `save as` with `in format save as PNG` caused parse errors because `as` is both a keyword and part of the enum value name. Multiple numeric code attempts also failed.
- **Fixed:** switched to Keynote, which can import PPTX and has a clean `export ... as slide images` command.

### Keynote PPTX import timing
- On first call, Keynote wasn't ready → empty tmp_dir → fallback to external PowerPoint.
- **Fixed:** poll-based wait (`repeat until count of slides > 0`) + cleanup empty cache dir on failure so next call retries.

### `winfo_width()` returning 1 before window realized
- ProjectionWindow in `overrideredirect` mode: `winfo_width()` returns 1 before rendering, causing `_size()` to return (1,1).
- **Fixed:** `_cached_size` stored in `_place_on_projector()`, used as fallback in `_size()`.

### Video black screen
- `c.delete("all") + c.create_image()` per frame on macOS causes black flash.
- **Fixed:** `c.itemconfigure(existing_item, image=new_photo)` to update in-place + `update_idletasks()`.

### `text_color="transparent"` in CTkButton
- customtkinter raises `ValueError: transparency is not allowed for this attribute` for text_color.
- **Fixed:** section rename/delete buttons use `text=""` when hidden, `text="✎"/"✕"` on hover.

### `CTkFrame.configure(width=nw)` not triggering grid relayout
- Setting width via CTkFrame.configure during drag doesn't force the grid geometry manager to recompute.
- **Fixed (not yet confirmed):** also call `outer.grid_columnconfigure(col, minsize=nw, weight=0)` + `update_idletasks()`. Also tries `outer._frame.columnconfigure()` in a try/except for CTkFrame internals.

### `_stop_projection` ↔ `ProjectionWindow.close()` infinite loop
- `close()` → `on_close()` → `_stop_projection()` → `projection.close()` → infinite recursion.
- **Fixed:** `close()` clears `_on_close = None` before calling it.

### Tkinter fullscreen + Escape on macOS
- With `-fullscreen True` (single monitor fallback), pressing Escape closes the window but previously didn't update the app pill.
- **Fixed:** `on_close` callback now wired to `_stop_projection`.

## ⚠️ Gotchas / Traps

- **Close Python before editing code** — user has 16GB RAM. Always `pkill -f "python.*main"` before starting a work session and immediately after testing.
- **macOS case-insensitive FS**: `HANDOFF.md` and `handoff.md` are the same file.
- **Don't reintroduce `Toplevel`** for editing popups — use `_open_modal`.
- **`cursor="hand2"`** was replaced with `"pointinghand"` — don't revert.
- **`text_color="transparent"`** crashes CTkButton — use `text=""` to hide button labels.
- **`acts.pack(side="right")` must come BEFORE `lbl.pack()`** in slot rows — otherwise `expand=True` on lbl takes all space and acts gets zero.
- **`on_close` re-entry guard**: `ProjectionWindow.close()` clears `_on_close = None` before calling it. Don't remove this.
- **Projection on single monitor** (no Sidecar): falls back to `-fullscreen True` on primary, covering the app window. The app is still running behind it; use `_stop_projection` / "Togli proiezione" to get back.
- **pgrep check timing**: `pgrep -f "python.*main"` after launching via osascript may return nothing for ~10s while Tk initializes — the app is still loading, not crashed.
- **`_dl_cancel`** is an instance attribute initialized to `False` in `_view_media()`. If the Media tab is never visited in a session, the attribute doesn't exist — access via `getattr(self, "_dl_cancel", False)` if needed outside `_view_media`.
- **Smoke tests** live in the scratchpad (session-specific path), NOT in the repo. Recreate if needed.
- **Reset `config/settings.json`** after smoke tests — tests dirty it.
